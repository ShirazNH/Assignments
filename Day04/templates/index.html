Calculate the mating efficiency index

Each male is tested with 4 hermaphrodites. His mating efficiency index is the fraction of those hermaphrodites that had progeny (0, 0.25, 0.5, 0.75 or 1). The tool calculates the index for every male, then the mean and standard deviation per genotype, and draws a bar plot.

1. Organize your data

Use an Excel file (.xlsx). The sheet you analyze must look like this:

  • First row = column names, spelled exactly as below (case-sensitive).
  • One row per male.
  • Genotype: the group the male belongs to (e.g. him-5, ces-2). Every row needs a value. Groups appear in the plot in the order they first appear in the sheet.
  • {% for c in herm_columns %}{{ c }}{% if not loop.last %}, {% endif %}{% endfor %}: one column per hermaphrodite, scored 1 = had progeny, 0 = no progeny. Only 0 or 1 are allowed, with no empty cells.
  • Other columns (e.g. male_number, notes) are allowed. They're kept in the output but not used.
  • A workbook may have several sheets. You choose which one to analyze in the next step.
